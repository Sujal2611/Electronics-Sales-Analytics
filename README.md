# Electronics Sales Analytics Dashboard

## Project Overview
An interactive Microsoft Excel dashboard developed to analyze electronics sales performance, revenue, profitability, product categories and regional trends using 1,500 sales records.

## Project Objectives
- Analyze overall sales and revenue performance.
- Evaluate product and category performance.
- Monitor profitability and sales trends.
- Understand regional and sales-channel performance.
- Present business insights through interactive dashboards.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Excel Charts
- KPI Cards
- Data Cleaning and Preparation
- Data Analysis

## Workbook Structure

| Sheet | Description |
|---|---|
| Dashboard | Main sales performance dashboard |
| Deep Dive | Detailed sales analysis |
| Guide | Dashboard usage instructions |
| Sales_Data | Source sales records |
| Data Cleaning & Preparation | Data quality audit and preparation |
| Calc | Dashboard calculation engine |

## Key Analysis Areas
- Revenue and profitability analysis
- Product and category performance
- Regional sales analysis
- Sales channel performance
- Order and payment analysis
- Interactive KPI reporting

## Dataset
The project uses 1,500 sales records containing order details, dates, locations, sales channels, product categories, quantities, prices, discounts, revenue, costs, profit and payment information.

## Business Value
The dashboard helps users monitor sales performance, identify profitable products, understand regional trends and support data-driven business decisions.
